# Claude Design reference

Source project: `Flighty clone for mobile platforms`

Imported from Claude Design project `6a11188e-c880-4d83-8117-01d6d9342eaf` on
2026-07-18 through the authenticated `claude-design` MCP. These files are the
visual source of truth for Cirrava's mobile implementation.

The v1 app follows the Terrella direction: a night-sky canvas, amber aircraft
signals, cyan planned routes, warm paper travel documents, Space Grotesk body
type, and Space Mono operational data. Product scope remains limited to one
anonymous followed flight; future trips, radar, passport, and authentication
surfaces shown in the reference are not part of this vertical slice.

# Derive meaningful Flight Events from Flight Snapshots

Cirrava stores each accepted normalized provider observation as a Flight Snapshot but creates a Flight Event only when comparison reveals a meaningful domain change. Repeated polls, provider wording differences, and unchanged snapshots do not create timeline entries or notifications. Aircraft position, altitude, speed, and route-point updates are Flight Telemetry rather than Flight Events; a true domain change such as a diversion still produces an event. Deterministic derivation, telemetry storage, and deduplication add processing complexity, but they preserve an explainable history and prevent noisy or duplicate user updates. This decision supersedes the planning baseline where altitude and route updates were listed as event types.
